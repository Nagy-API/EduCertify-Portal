## Project Description
Academic Course & Certification Portal allows students to enroll in programs, track progress, complete units, and receive digital credentials.

## Technologies
- JavaFX
- SQL Server
- JDBC
- SQL

## Database
Database name: AcademicPortal

SQL files:
- database/AcademicPortal_DDL.sql
- database/AcademicPortal_Queries.sql

## Main Features
- Student Management
- Instructor Management
- Category Management
- Program Management
- Unit Management
- Enrollment Management
- Progress Tracking
- Credential Issuing and Verification
- Reports

## How to Run
1. Open SQL Server.
2. Run database/AcademicPortal_DDL.sql.
3. Open the JavaFX project from app/AcademicPortalApp.
4. Update database connection settings in DatabaseConnection.java.
5. Run Main.java.
